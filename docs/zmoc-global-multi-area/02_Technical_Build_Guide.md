## 1. Dictionary

### 1.1 Area Scope

| Object | Definition |
| --- | --- |
| Domain `ZMOC_SCOPE_DO` | CHAR 1; fixed values `S` = *Single Area*, `M` = *Multiple Areas*, `G` = *Global* |
| Data element `ZMOC_SCOPE_DE` | Domain `ZMOC_SCOPE_DO`; labels: short *Scope*, medium *Area Scope*, long *MOC Area Scope*, heading *Area Scope*; Further Characteristics → **Change Document** ✔ |
| Append `ZMOC_ROOT_S` (append to the extension include `/IAM/INCL_EEW_I_ROOT`) | New field after `Z_MOC_ASTA_DES`: `Z_MOC_SCOPE TYPE ZMOC_SCOPE_DE` |

### 1.2 Longer area text

| Object | Definition |
| --- | --- |
| Domain `ZMOC_AREA_TXT_DO` | CHAR 255, **lower case** ✔ |
| Data element `ZANAME_DE` (existing) | Change domain `CHAR80` → `ZMOC_AREA_TXT_DO`; set **Change Document** ✔ |

`ZANAME_DE` is used only by ZMOC objects (append, `ZMOC_CL_ACT_NOTIFICATION`, `ZMOC_CL_ACTIVITY_WF_CONNECT`, `ZMOC_OWNER_NOTIF`, the two reminder reports, the CDS extension views). Activation adjusts `/IAM/D_I_ROOT` (lengthening a character column – no conversion on HANA); check the SE14 log.

### 1.3 Area node

| Object | Definition |
| --- | --- |
| Data element `ZMOC_AREA_CODE_DE` | CHAR 20, label *Area Code* (value of location identifier `ZLOC_ID`, e.g. `A1`) |
| Structure `ZMOC_S_ISS_AREA_D` (node data) | `LOC_ROOT_KEY TYPE EHFND_LOC_ROOT_KEY`, `AREA_ID TYPE ZAREADID_DE`, `AREA_CODE TYPE ZMOC_AREA_CODE_DE`, `AREA_NAME TYPE EHFND_LOC_REVISION_TEXT` |
| Structure `ZMOC_S_ISS_AREA` (combined) | `.INCLUDE /BOBF/S_FRW_KEY_INCL`, `.INCLUDE ZMOC_S_ISS_AREA_D` |
| Table type `ZMOC_T_ISS_AREA` | Standard table of `ZMOC_S_ISS_AREA` |
| Table `ZMOC_D_ISS_AREA` | Delivery class A; `MANDT` (key), `DB_KEY TYPE /BOBF/CONF_KEY` (key), `PARENT_KEY`, `ROOT_KEY` (`/BOBF/CONF_KEY`), `.INCLUDE ZMOC_S_ISS_AREA_D`; secondary index `Z01` on `MANDT, PARENT_KEY` |

BOBX can generate the combined structure, table type and table in step 2.2 – then only `ZMOC_S_ISS_AREA_D` is created by hand.

### 1.4 Messages `ZMOC_MSG`

| No. | Text |
| --- | --- |
| 031 | Area Manager is mandatory for &1 MOC. Select at least one Area Manager in People Involved |
| 032 | Select at least two areas for a Multiple Areas MOC |
| 033 | Emergency MOC after office hours: consider adding the Site Shift Manager |
| 034 | Area Scope and areas can only be changed while the MOC is In Preparation |
| 035 | MOC number cannot be built: segment &1 is too long (MOC number max. 20 characters) |
| 036 | Area Manager / Site Shift Manager are not determined automatically for this scope - maintain them in People Involved |

### 1.5 Variable

TVARVC (STVARV) **select option** `ZMOC_BT_TEAM_GLOBAL`: one e-mail address per line in `LOW` (sign `I`, option `EQ`). Used as CC on TRC (Z06) and VP Committee (Z19) approval of Global MOCs.

## 2. BOPF enhancement of `/IAM/ISSUE` (BOBX)

`/IAM/ISSUE` is extensible (`/BOBF/OBM_OBJ-EXTENDIBLE = X`). Do the Phase-0 spike first.

1. **BOBX** → business object `/IAM/ISSUE` → context menu **Create Enhancement**.
   Enhancement object `ZMOC_ISSUE_ENH`, description *MOC – Area Scope*, constants interface `ZIF_MOC_ISSUE_X_C`, package `ZMOC`.
2. In `ZMOC_ISSUE_ENH`: node **ROOT** → **Create Subnode**
   * Node name `ZZ_AREA`, node type *Persistent*
   * Data structure `ZMOC_S_ISS_AREA_D`, combined structure `ZMOC_S_ISS_AREA`, combined table type `ZMOC_T_ISS_AREA`, database table `ZMOC_D_ISS_AREA`
   * Data access class `/BOBF/CL_DAC_TABLE`, lock via ROOT (inherited)
   * The composition association ROOT → ZZ_AREA (cardinality 0..n) is created with the node; name `ZZ_AREA`.
3. Node **ROOT** → **Determinations** → Create `ZZ_SET_SCOPE_DATA`
   * Class `ZCL_MOC_D_SCOPE_DATA` (section 4)
   * Category *Derive dependent data immediately after modification*
   * Trigger conditions: `ROOT` – Create, Update; `ZZ_AREA` – Create, Update, Delete
   * Evaluation time point: *After Modify*
4. Optional (decision Q6 = lock after submission): validation `ZZ_CHECK_SCOPE_LOCK` on ROOT, class `ZCL_MOC_V_SCOPE_LOCK` (section 4.2).
5. Generate the constants interface, check and activate. Expected constants `<generated>`:
   `ZIF_MOC_ISSUE_X_C=>SC_NODE-ZZ_AREA`, `ZIF_MOC_ISSUE_X_C=>SC_ASSOCIATION-ROOT-ZZ_AREA`.
6. **BOBT** test: load a MOC, create two `ZZ_AREA` instances, set `Z_MOC_SCOPE = 'M'` on ROOT → `Z_AREA_NAME` must show both names, `Z_UNIT_NAME = 'N/A'`; save; reload.

### 3.2 Implementation

```abap
CLASS zcl_moc_scope_service IMPLEMENTATION.

  METHOD normalize_scope.
    rv_scope = COND #( WHEN iv_scope IS INITIAL THEN gc_scope-single ELSE iv_scope ).
  ENDMETHOD.


  METHOD is_auto_responsible_active.
    rv_active = xsdbool( normalize_scope( iv_scope ) = gc_scope-single ).
  ENDMETHOD.


  METHOD is_scope_change_allowed.
    DATA lv_admin TYPE abap_boolean.

    IF iv_lcycle_cd IS INITIAL
       OR iv_lcycle_cd = /iam/if_i_issue_status_c=>sc_root-lifecycle-v_in_preparation.
      rv_allowed = abap_true.
      RETURN.
    ENDIF.

    " After submission only MOC administrators (TVARVC ZEHS_MOC_ADMIN_ROLE).
    " Buffered: GET_DATA of the root form calls this in every roundtrip.
    IF gv_admin_known = abap_false.
      CALL FUNCTION 'ZMOC_CHK_ADMIN_ROLE'
        EXPORTING
          im_uname = sy-uname
        IMPORTING
          ex_auth  = lv_admin.
      gv_is_admin    = lv_admin.
      gv_admin_known = abap_true.
    ENDIF.

    rv_allowed = gv_is_admin.
  ENDMETHOD.


  METHOD get_moc_area_master.
    IF gt_area_master IS INITIAL.
      SELECT DISTINCT a~parent_key AS loc_root_key,
                      e~id         AS area_id,
                      d~identifier AS area_code,
                      b~text       AS area_name
        FROM ehfndd_loc_rev AS a
        INNER JOIN ehfndd_loc_idf  AS c ON  c~parent_key = a~db_key
                                        AND c~type       = @gc_idf_moc_area
                                        AND c~identifier = @abap_true
        INNER JOIN ehfndd_loc_idf  AS d ON  d~parent_key = a~db_key
                                        AND d~type       = @gc_idf_loc_code
        INNER JOIN ehfndd_loc_text AS b ON  b~parent_key = a~db_key
        INNER JOIN ehfndd_loc_root AS e ON  e~db_key     = a~parent_key
        WHERE a~type     = @gc_area_type
          AND a~end_date = @gc_end_date
          AND b~language = @sy-langu
        ORDER BY area_name
        INTO TABLE @DATA(lt_master).

      gt_area_master = VALUE #( FOR ls_master IN lt_master
                                ( loc_root_key = ls_master-loc_root_key
                                  area_id      = ls_master-area_id
                                  area_code    = CONV #( ls_master-area_code )
                                  area_name    = ls_master-area_name ) ).
    ENDIF.

    rt_area = gt_area_master.
  ENDMETHOD.


  METHOD get_area.
    CHECK iv_area_key IS NOT INITIAL.

    " Z_AREK_KEY holds the location root UUID as 32 hex characters
    DATA(lv_loc_key) = CONV ehfnd_loc_root_key( iv_area_key ).

    SELECT SINGLE a~parent_key AS loc_root_key,
                  e~id         AS area_id,
                  b~text       AS area_name
      FROM ehfndd_loc_rev AS a
      INNER JOIN ehfndd_loc_text AS b ON b~parent_key = a~db_key
      INNER JOIN ehfndd_loc_root AS e ON e~db_key     = a~parent_key
      WHERE a~parent_key = @lv_loc_key
        AND a~end_date   = @gc_end_date
        AND b~language   = @sy-langu
      INTO CORRESPONDING FIELDS OF @rs_area.

    IF sy-subrc = 0.
      rs_area-area_code = get_location_code( iv_area_key ).
    ENDIF.
  ENDMETHOD.


  METHOD get_location_code.
    CHECK iv_loc_key IS NOT INITIAL.

    DATA(lv_loc_key) = CONV ehfnd_loc_root_key( iv_loc_key ).

    SELECT SINGLE d~identifier
      FROM ehfndd_loc_rev AS a
      INNER JOIN ehfndd_loc_idf AS d ON d~parent_key = a~db_key
      WHERE a~parent_key = @lv_loc_key
        AND a~end_date   = @gc_end_date
        AND d~type       = @gc_idf_loc_code
      INTO @DATA(lv_identifier).

    IF sy-subrc = 0.
      rv_code = condense( CONV string( lv_identifier ) ).
    ENDIF.
  ENDMETHOD.


  METHOD get_selected_areas.
    DATA lt_node TYPE zmoc_t_iss_area.

    CHECK iv_issue_key IS NOT INITIAL.

    IF iv_from_buffer = abap_true.
      " BOPF buffer - contains the not yet saved changes of the running transaction
      TRY.
          DATA(lo_srv_mgr) = /bobf/cl_tra_serv_mgr_factory=>get_service_manager(
                               /iam/if_i_issue_c=>sc_bo_key ).
          lo_srv_mgr->retrieve_by_association(
            EXPORTING
              iv_node_key    = /iam/if_i_issue_c=>sc_node-root
              it_key         = VALUE #( ( key = iv_issue_key ) )
              iv_association = zif_moc_issue_x_c=>sc_association-root-zz_area
              iv_fill_data   = abap_true
            IMPORTING
              et_data        = lt_node ).
        CATCH /bobf/cx_frw.
          CLEAR lt_node.
      ENDTRY.
      rt_area = map_nodes_to_areas( lt_node ).
    ELSE.
      " Committed data - background processing (notifications)
      SELECT loc_root_key, area_id, area_code, area_name
        FROM zmoc_d_iss_area
        WHERE parent_key = @iv_issue_key
        INTO CORRESPONDING FIELDS OF TABLE @rt_area.
    ENDIF.
  ENDMETHOD.


  METHOD set_selected_areas.
    DATA lt_node TYPE zmoc_t_iss_area.
    DATA lt_mod  TYPE /bobf/t_frw_modification.

    CLEAR eo_message.

    DATA(lo_srv_mgr) = /bobf/cl_tra_serv_mgr_factory=>get_service_manager(
                         /iam/if_i_issue_c=>sc_bo_key ).

    lo_srv_mgr->retrieve_by_association(
      EXPORTING
        iv_node_key    = /iam/if_i_issue_c=>sc_node-root
        it_key         = VALUE #( ( key = iv_issue_key ) )
        iv_association = zif_moc_issue_x_c=>sc_association-root-zz_area
        iv_fill_data   = abap_true
      IMPORTING
        et_data        = lt_node ).

    " Areas that were deselected
    LOOP AT lt_node INTO DATA(ls_node).
      IF line_exists( it_area[ loc_root_key = ls_node-loc_root_key ] ).
        CONTINUE.
      ENDIF.
      APPEND VALUE #( node        = zif_moc_issue_x_c=>sc_node-zz_area
                      change_mode = /bobf/if_frw_c=>sc_modify_delete
                      key         = ls_node-key
                      root_key    = iv_issue_key ) TO lt_mod.
    ENDLOOP.

    " Areas that were added
    LOOP AT it_area INTO DATA(ls_area).
      IF line_exists( lt_node[ loc_root_key = ls_area-loc_root_key ] ).
        CONTINUE.
      ENDIF.
      DATA(lv_key) = /bobf/cl_frw_factory=>get_new_key( ).
      APPEND VALUE #( node        = zif_moc_issue_x_c=>sc_node-zz_area
                      change_mode = /bobf/if_frw_c=>sc_modify_create
                      key         = lv_key
                      source_node = /iam/if_i_issue_c=>sc_node-root
                      source_key  = iv_issue_key
                      association = zif_moc_issue_x_c=>sc_association-root-zz_area
                      root_key    = iv_issue_key
                      data        = NEW zmoc_s_iss_area( key          = lv_key
                                                         parent_key   = iv_issue_key
                                                         root_key     = iv_issue_key
                                                         loc_root_key = ls_area-loc_root_key
                                                         area_id      = ls_area-area_id
                                                         area_code    = ls_area-area_code
                                                         area_name    = ls_area-area_name ) ) TO lt_mod.
    ENDLOOP.

    CHECK lt_mod IS NOT INITIAL.

    lo_srv_mgr->modify(
      EXPORTING
        it_modification = lt_mod
      IMPORTING
        eo_message      = eo_message ).
  ENDMETHOD.


  METHOD map_nodes_to_areas.
    rt_area = CORRESPONDING #( it_node ).
  ENDMETHOD.


  METHOD build_display.
    DATA lv_area_text  TYPE zaname_de.
    DATA lv_max_length TYPE i.
    DATA lv_text       TYPE string.
    DATA lv_next       TYPE string.
    DATA lv_rest       TYPE i.
    DATA lv_shown      TYPE i.

    CASE normalize_scope( iv_scope ).

      WHEN gc_scope-global.
        rs_display-area_name = gc_text-global.
        rs_display-unit_name = gc_text-global.

      WHEN gc_scope-multiple.
        " Field length of Z_AREA_NAME (255 after the domain change, 80 before)
        DESCRIBE FIELD lv_area_text LENGTH lv_max_length IN CHARACTER MODE.

        DATA(lt_area) = it_area.
        SORT lt_area BY area_name loc_root_key.
        DELETE ADJACENT DUPLICATES FROM lt_area COMPARING loc_root_key.
        DATA(lv_total) = lines( lt_area ).

        LOOP AT lt_area INTO DATA(ls_area).
          lv_next = COND #( WHEN lv_shown = 0
                            THEN condense( CONV string( ls_area-area_name ) )
                            ELSE |{ lv_text }, { condense( CONV string( ls_area-area_name ) ) }| ).
          lv_rest = lv_total - lv_shown - 1.
          " keep room for the suffix ' (+n more)' while not all names fit
          IF strlen( lv_next ) > lv_max_length
             OR ( lv_rest > 0 AND strlen( lv_next ) + strlen( | (+{ lv_rest } more)| ) > lv_max_length ).
            EXIT.
          ENDIF.
          lv_text  = lv_next.
          lv_shown = lv_shown + 1.
        ENDLOOP.

        IF lv_shown < lv_total.
          lv_text = |{ lv_text } (+{ lv_total - lv_shown } more)|.
        ENDIF.

        rs_display-area_name = lv_text.
        rs_display-unit_name = gc_text-not_applicable.

      WHEN OTHERS.
        " Single Area: texts are derived from the selected area/unit by the
        " post-exit ZENH_MOC_UPDT_ROOT_ZFLDS1 - nothing to do here
    ENDCASE.
  ENDMETHOD.


  METHOD get_number_segment.
    CASE normalize_scope( iv_scope ).
      WHEN gc_scope-global.
        rv_segment = gc_nr_segment-global.
      WHEN gc_scope-multiple.
        rv_segment = gc_nr_segment-multiple.
      WHEN OTHERS.
        DATA(lt_code) = VALUE string_table( ( get_location_code( iv_area_key ) )
                                            ( get_location_code( iv_unit_key ) ) ).
        " no empty segment - avoids numbers like 'MOC-26-A1--742'
        DELETE lt_code WHERE table_line IS INITIAL.
        rv_segment = concat_lines_of( table = lt_code sep = gc_separator ).
    ENDCASE.
  ENDMETHOD.


  METHOD get_number_range_interval.
    " One counter for all scopes. For own Global / Multiple counters (decision Q2)
    " return '02' / '03' here and freeze the scope after the first save.
    rv_interval = gc_nr_interval.
  ENDMETHOD.


  METHOD build_moc_id.
    DATA(lt_part) = VALUE string_table( ( gc_moc_prefix )
                                        ( condense( CONV string( iv_year ) ) )
                                        ( condense( CONV string( iv_segment ) ) )
                                        ( condense( CONV string( iv_sequence ) ) ) ).
    DELETE lt_part WHERE table_line IS INITIAL.
    rv_moc_id = concat_lines_of( table = lt_part sep = gc_separator ).
  ENDMETHOD.


  METHOD rebuild_moc_id.
    " MOC-26-A1-U111-742 / MOC-26-A1--742 / MOC-26-GLOBAL-742  ->  MOC-26-<segment>-742
    DATA(lv_old_id) = condense( CONV string( iv_old_moc_id ) ).
    DATA(lv_last)   = find( val = lv_old_id sub = gc_separator occ = -1 ).

    IF lv_last <= 0 OR lv_old_id NP |{ gc_moc_prefix }{ gc_separator }*|.
      RETURN.        " not a custom MOC number - leave it untouched
    ENDIF.

    TRY.
        DATA(lv_year) = segment( val = lv_old_id index = 2 sep = gc_separator ).
      CATCH cx_sy_strg_par_val.
        RETURN.
    ENDTRY.

    rv_moc_id = build_moc_id( iv_year     = lv_year
                              iv_segment  = iv_segment
                              iv_sequence = substring( val = lv_old_id off = lv_last + 1 ) ).
  ENDMETHOD.


  METHOD is_moc_id_valid.
    DATA lv_issue_id   TYPE /iam/issue_id.
    DATA lv_max_length TYPE i.

    DESCRIBE FIELD lv_issue_id LENGTH lv_max_length IN CHARACTER MODE.
    rv_valid = xsdbool( strlen( iv_moc_id ) <= lv_max_length ).
  ENDMETHOD.


  METHOD get_bt_team_cc.
    DATA lt_loc_key TYPE STANDARD TABLE OF ehfnd_loc_root_key WITH EMPTY KEY.

    SELECT SINGLE z_moc_scope, z_arek_key
      FROM /iam/d_i_root
      WHERE db_key = @iv_issue_key
      INTO @DATA(ls_root).

    CHECK sy-subrc = 0.

    CASE normalize_scope( ls_root-z_moc_scope ).

      WHEN gc_scope-global.
        " Site-wide distribution list (select option, one e-mail per line)
        SELECT low
          FROM tvarvc
          WHERE name = @gc_tvarvc_bt_glob
            AND type = 'S'
          INTO TABLE @DATA(lt_tvarvc).

        rt_cc = VALUE #( FOR ls_tvarvc IN lt_tvarvc WHERE ( low IS NOT INITIAL )
                         ( CONV ad_smtpadr( ls_tvarvc-low ) ) ).

      WHEN gc_scope-multiple.
        lt_loc_key = VALUE #( FOR ls_area IN get_selected_areas( iv_issue_key   = iv_issue_key
                                                                 iv_from_buffer = abap_false )
                              ( ls_area-loc_root_key ) ).

      WHEN OTHERS.
        IF ls_root-z_arek_key IS NOT INITIAL.
          lt_loc_key = VALUE #( ( CONV #( ls_root-z_arek_key ) ) ).
        ENDIF.
    ENDCASE.

    IF lt_loc_key IS NOT INITIAL.
      SELECT d~identifier
        FROM ehfndd_loc_rev AS a
        INNER JOIN ehfndd_loc_idf AS d ON d~parent_key = a~db_key
        FOR ALL ENTRIES IN @lt_loc_key
        WHERE a~parent_key = @lt_loc_key-table_line
          AND a~end_date   = @gc_end_date
          AND d~type       = @gc_idf_bt_team
        INTO TABLE @DATA(lt_identifier).

      rt_cc = VALUE #( BASE rt_cc
                       FOR ls_identifier IN lt_identifier WHERE ( identifier IS NOT INITIAL )
                       ( CONV ad_smtpadr( ls_identifier-identifier ) ) ).
    ENDIF.

    SORT rt_cc.
    DELETE ADJACENT DUPLICATES FROM rt_cc.
  ENDMETHOD.


  METHOD check_submit.
    DATA(lv_scope) = normalize_scope( is_root-z_moc_scope ).

    CASE lv_scope.

      WHEN gc_scope-single.
        " unchanged rules: area mandatory, unit mandatory when the area has units
        IF is_root-z_arek_key IS INITIAL.
          add_msg( EXPORTING iv_msgno = '000' iv_attribute = `Z_AREK_KEY`
                   CHANGING  ct_msg   = rt_msg ).
        ELSEIF is_root-z_unit_key IS INITIAL
           AND zcl_ehsm_utility=>zis_unit_available(
                 im_area_key = CONV /bobf/conf_key( is_root-z_arek_key ) ) = abap_true.
          add_msg( EXPORTING iv_msgno = '001' iv_attribute = `Z_UNIT_KEY`
                   CHANGING  ct_msg   = rt_msg ).
        ENDIF.

      WHEN gc_scope-multiple.
        IF lines( it_area ) < gc_min_areas_multiple.
          add_msg( EXPORTING iv_msgno = '032' iv_attribute = `Z_AREA_NAME`
                   CHANGING  ct_msg   = rt_msg ).
        ENDIF.

      WHEN gc_scope-global.
        " no area / unit required

    ENDCASE.

    " Area Manager approves Initial Review (Z04), Startup (Z10) and Final Approval (Z33).
    " For Global / Multiple it is not derived, so it must be maintained manually.
    " Decision Q7: drop the scope condition to apply this to Single Area as well.
    IF lv_scope <> gc_scope-single
       AND NOT line_exists( it_party[ party_role_code = gc_role_area_manager ] ).
      add_msg( EXPORTING iv_msgno = '031'
                         iv_msgv1 = SWITCH string( lv_scope WHEN gc_scope-global THEN gc_text-global
                                                            ELSE gc_text-multiple )
               CHANGING  ct_msg   = rt_msg ).
    ENDIF.

    " Emergency MOC after office hours: Initial Review is routed to the Site Shift Manager
    IF lv_scope <> gc_scope-single
       AND is_root-issue_type = gc_issue_type_emg
       AND is_after_office_hours( ) = abap_true
       AND NOT line_exists( it_party[ party_role_code = gc_role_shift_manager ] ).
      add_msg( EXPORTING iv_msgty = 'W' iv_msgno = '033'
               CHANGING  ct_msg   = rt_msg ).
    ENDIF.
  ENDMETHOD.


  METHOD get_changed_root_fields.
    CONSTANTS lc_fields TYPE string
      VALUE `Z_MOC_SCOPE Z_AREK_KEY Z_UNIT_KEY Z_AREA_ID Z_AREA_NAME Z_UNIT_ID Z_UNIT_NAME`.

    SPLIT lc_fields AT space INTO TABLE DATA(lt_field).

    LOOP AT lt_field INTO DATA(lv_field).
      ASSIGN COMPONENT lv_field OF STRUCTURE is_old TO FIELD-SYMBOL(<lv_old>).
      ASSIGN COMPONENT lv_field OF STRUCTURE is_new TO FIELD-SYMBOL(<lv_new>).
      IF <lv_old> IS ASSIGNED AND <lv_new> IS ASSIGNED AND <lv_old> <> <lv_new>.
        APPEND lv_field TO rt_changed.
      ENDIF.
      UNASSIGN: <lv_old>, <lv_new>.
    ENDLOOP.
  ENDMETHOD.


  METHOD is_after_office_hours.
    rv_after_hours = xsdbool( sy-uzeit < gc_office_start OR sy-uzeit > gc_office_end ).
  ENDMETHOD.


  METHOD add_msg.
    APPEND VALUE #( msg       = VALUE #( msgty = iv_msgty
                                         msgid = gc_msgid
                                         msgno = iv_msgno
                                         msgv1 = iv_msgv1 )
                    attribute = iv_attribute ) TO ct_msg.
  ENDMETHOD.

ENDCLASS.
```

### 4.1 Determination `ZZ_SET_SCOPE_DATA` – class `ZCL_MOC_D_SCOPE_DATA`

Assigned to ROOT (section 2, step 3). Keeps root fields and area nodes consistent with the scope – for every channel (UI, workflow, API). Writes only real changes, so a second run finds nothing to do.

```abap
CLASS zcl_moc_d_scope_data DEFINITION
  PUBLIC
  INHERITING FROM /bobf/cl_lib_d_superclass
  FINAL
  CREATE PUBLIC.

*&---------------------------------------------------------------------*
*& Object ID   : CRQ<new> (Global / Multiple-Area MOC)                  *
*& Description : Determination ZZ_SET_SCOPE_DATA on /IAM/ISSUE ROOT     *
*&  - default Area Scope 'S'                                            *
*&  - leaving Single Area: keep the area as first entry (Multiple),     *

CLASS zcl_moc_d_scope_data IMPLEMENTATION.

  METHOD /bobf/if_frw_determination~execute.

    DATA lt_root  TYPE /iam/t_i_root.
    DATA lt_node  TYPE zmoc_t_iss_area.
    DATA lt_party TYPE /iam/t_i_party.

    CLEAR: eo_message, et_failed_key.

    " Triggered from ROOT or from ZZ_AREA: always work on the ROOT keys
    " (with a ZZ_AREA trigger is_ctx-node_key / it_key belong to ZZ_AREA)

      lt_root_key = it_key.
    ELSE.
      io_read->get_root_key( EXPORTING iv_node       = is_ctx-node_key
                                       it_key        = it_key
                             IMPORTING et_target_key = lt_root_key ).
      SORT lt_root_key BY key.
      DELETE ADJACENT DUPLICATES FROM lt_root_key COMPARING key.
    ENDIF.

    io_read->retrieve(
      EXPORTING
        iv_node       = /iam/if_i_issue_c=>sc_node-root
        it_key        = lt_root_key
      IMPORTING
        et_data       = lt_root ).

    io_read->retrieve_by_association(
      EXPORTING
        iv_node        = /iam/if_i_issue_c=>sc_node-root
        it_key         = lt_root_key
        iv_association = zif_moc_issue_x_c=>sc_association-root-zz_area
        iv_fill_data   = abap_true
      IMPORTING
        et_data        = lt_node ).

    io_read->retrieve_by_association(
      EXPORTING
        iv_node        = /iam/if_i_issue_c=>sc_node-root
        it_key         = lt_root_key
        iv_association = /iam/if_i_issue_c=>sc_association-root-party
        iv_fill_data   = abap_true
      IMPORTING
        et_data        = lt_party ).

    LOOP AT lt_root REFERENCE INTO DATA(lr_root).

      " /IAM/ISSUE is shared by all IAM applications - act on MOC records only
      IF lr_root->application <> /iam/if_appl_c=>sc_application-moc.
        CONTINUE.
      ENDIF.

      DATA(ls_before)    = lr_root->*.
      DATA(lv_scope)     = zcl_moc_scope_service=>normalize_scope( lr_root->z_moc_scope ).
      DATA(lt_area_node) = VALUE zmoc_t_iss_area( FOR ls_n IN lt_node
                                                  WHERE ( parent_key = lr_root->key )
                                                  ( ls_n ) ).
      DATA(lt_area)      = zcl_moc_scope_service=>map_nodes_to_areas( lt_area_node ).

      lr_root->z_moc_scope = lv_scope.            " 'S' for new and old MOCs

      IF lv_scope <> zcl_moc_scope_service=>gc_scope-single.

        " Scope was just switched away from Single Area while an area was selected
        IF lr_root->z_arek_key IS NOT INITIAL OR lr_root->z_unit_key IS NOT INITIAL.

          " Single -> Multiple: the area chosen so far becomes the first entry
          IF lv_scope = zcl_moc_scope_service=>gc_scope-multiple
             AND lr_root->z_arek_key IS NOT INITIAL
             AND lt_area_node IS INITIAL.
            DATA(ls_area) = zcl_moc_scope_service=>get_area( lr_root->z_arek_key ).
            IF ls_area-loc_root_key IS NOT INITIAL.
              io_modify->create(
                iv_node            = zif_moc_issue_x_c=>sc_node-zz_area
                is_data            = NEW zmoc_s_iss_area( loc_root_key = ls_area-loc_root_key
                                                          area_id      = ls_area-area_id
                                                          area_code    = ls_area-area_code
                                                          area_name    = ls_area-area_name )
                iv_assoc_key       = zif_moc_issue_x_c=>sc_association-root-zz_area
                iv_source_node_key = /iam/if_i_issue_c=>sc_node-root
                iv_source_key      = lr_root->key
                iv_root_key        = lr_root->key ).
              APPEND ls_area TO lt_area.
            ENDIF.
          ENDIF.

          " Area Manager / Site Shift Manager derived from that area are not valid any more
          LOOP AT lt_party INTO DATA(ls_party)
               WHERE parent_key = lr_root->key
                 AND ( party_role_code = zcl_moc_scope_service=>gc_role_area_manager
                    OR party_role_code = zcl_moc_scope_service=>gc_role_shift_manager ).
            io_modify->delete( iv_node     = /iam/if_i_issue_c=>sc_node-party
                               iv_key      = ls_party-key
                               iv_root_key = lr_root->key ).
            zcl_moc_scope_service=>gv_responsibles_reset = abap_true.
          ENDLOOP.

          CLEAR: lr_root->z_arek_key, lr_root->z_unit_key.
        ENDIF.

        DATA(ls_display) = zcl_moc_scope_service=>build_display( iv_scope = lv_scope
                                                                 it_area  = lt_area ).
        lr_root->z_area_name = ls_display-area_name.
        lr_root->z_area_id   = ls_display-area_id.
        lr_root->z_unit_name = ls_display-unit_name.
        lr_root->z_unit_id   = ls_display-unit_id.

      ELSE.
        " Single Area: names/IDs come from ZENH_MOC_UPDT_ROOT_ZFLDS1;
        " remove texts left over from Global / Multiple
        IF lr_root->z_arek_key IS INITIAL.
          CLEAR: lr_root->z_area_name, lr_root->z_area_id.
        ENDIF.
        IF lr_root->z_unit_key IS INITIAL.
          CLEAR: lr_root->z_unit_name, lr_root->z_unit_id.
        ENDIF.
      ENDIF.

      " Area rows exist only for scope Multiple
      IF lv_scope <> zcl_moc_scope_service=>gc_scope-multiple.
        LOOP AT lt_area_node INTO DATA(ls_node).
          io_modify->delete( iv_node     = zif_moc_issue_x_c=>sc_node-zz_area
                             iv_key      = ls_node-key
                             iv_root_key = lr_root->key ).
        ENDLOOP.
      ENDIF.

      " Write back only real changes
      DATA(lt_changed) = zcl_moc_scope_service=>get_changed_root_fields( is_old = ls_before
                                                                         is_new = lr_root->* ).
      IF lt_changed IS NOT INITIAL.
        io_modify->update( iv_node           = /iam/if_i_issue_c=>sc_node-root
                           iv_key            = lr_root->key
                           iv_root_key       = lr_root->key
                           is_data           = lr_root
                           it_changed_fields = lt_changed ).
      ENDIF.

    ENDLOOP.

  ENDMETHOD.

ENDCLASS.
```

```abap
    ENDLOOP.
  ENDMETHOD.


  METHOD if_fpm_guibb_list~flush.
    FIELD-SYMBOLS <lt_data> TYPE STANDARD TABLE.

    CHECK it_change_log IS NOT INITIAL AND it_data IS BOUND.
    ASSIGN it_data->* TO <lt_data>.
    CHECK <lt_data> IS ASSIGNED.
    MOVE-CORRESPONDING <lt_data> TO mt_row.
  ENDMETHOD.


  METHOD if_fpm_guibb_list~process_event.
    DATA lv_button TYPE string.

    ev_result = if_fpm_constants=>gc_event_result-ok.

    CASE io_event->mv_event_id.

      WHEN gc_evt_select_all OR gc_evt_clear_all.
        IF mv_editable = abap_true.
          DATA(lv_selected) = xsdbool( io_event->mv_event_id = gc_evt_select_all ).
          MODIFY mt_row FROM VALUE #( selected = lv_selected ) TRANSPORTING selected
                 WHERE selected <> lv_selected.
        ENDIF.

      WHEN cl_fpm_event=>gc_event_close_dialog_box.
        IF io_event->mo_event_data IS BOUND.
          io_event->mo_event_data->get_value( EXPORTING iv_key   = if_fpm_constants=>gc_dialog_box-dialog_buton_key
                                              IMPORTING ev_value = lv_button ).
        ENDIF.
        IF lv_button = if_fpm_constants=>gc_dialog_action_id-ok AND mv_editable = abap_true.
          " FAILED keeps the dialog open (e.g. fewer than two areas)
          apply_selection( IMPORTING et_messages = et_messages
                                     ev_result   = ev_result ).
        ENDIF.

    ENDCASE.
  ENDMETHOD.


  METHOD if_fpm_guibb_list~get_default_config.
  ENDMETHOD.


  METHOD if_fpm_guibb_list~check_config.
  ENDMETHOD.


  METHOD load_rows.
    DATA(lt_selected) = zcl_moc_scope_service=>get_selected_areas( mv_issue_key ).

    mt_row = VALUE #( FOR ls_master IN zcl_moc_scope_service=>get_moc_area_master( )
                      ( selected     = xsdbool( line_exists( lt_selected[ loc_root_key = ls_master-loc_root_key ] ) )
                        area_code    = ls_master-area_code
                        area_name    = ls_master-area_name
                        area_id      = ls_master-area_id
                        loc_root_key = ls_master-loc_root_key ) ).

    " Areas selected earlier but no longer MOC-relevant stay visible and selected
    LOOP AT lt_selected INTO DATA(ls_selected).
      IF NOT line_exists( mt_row[ loc_root_key = ls_selected-loc_root_key ] ).
        APPEND VALUE #( selected     = abap_true
                        area_code    = ls_selected-area_code
                        area_name    = ls_selected-area_name
                        area_id      = ls_selected-area_id
                        loc_root_key = ls_selected-loc_root_key ) TO mt_row.
      ENDIF.
    ENDLOOP.

    IF mv_editable = abap_false.
      DELETE mt_row WHERE selected = abap_false.        " display: selected areas only
    ENDIF.

    SORT mt_row BY selected DESCENDING area_name ASCENDING.
  ENDMETHOD.


  METHOD apply_selection.
    DATA lt_bopf_msg TYPE /bobf/t_frw_message_k.
    DATA lo_message  TYPE REF TO /bobf/if_frw_message.

    CLEAR et_messages.
    ev_result = if_fpm_constants=>gc_event_result-ok.

    DATA(lt_area) = VALUE zcl_moc_scope_service=>tt_area(
                      FOR ls_row IN mt_row WHERE ( selected = abap_true )
                      ( loc_root_key = ls_row-loc_root_key
                        area_id      = ls_row-area_id
                        area_code    = ls_row-area_code
                        area_name    = ls_row-area_name ) ).

    IF lines( lt_area ) < zcl_moc_scope_service=>gc_min_areas_multiple.
      et_messages = VALUE #( ( msgid    = zcl_moc_scope_service=>gc_msgid
                               msgno    = '032'
                               severity = 'E' ) ).
      ev_result = if_fpm_constants=>gc_event_result-failed.
      RETURN.
    ENDIF.

    TRY.
        zcl_moc_scope_service=>set_selected_areas( EXPORTING iv_issue_key = mv_issue_key
                                                             it_area      = lt_area
                                                   IMPORTING eo_message   = lo_message ).
      CATCH /bobf/cx_frw INTO DATA(lx_frw).
        et_messages = VALUE #( ( msgid       = '00'
                                 msgno       = '208'
                                 severity    = 'E'
                                 parameter_1 = CONV #( lx_frw->get_text( ) ) ) ).
        ev_result = if_fpm_constants=>gc_event_result-failed.
        RETURN.
    ENDTRY.

    IF lo_message IS BOUND AND lo_message->check( ) = abap_true.
      lo_message->get_messages( IMPORTING et_message = lt_bopf_msg ).
      et_messages = VALUE #( FOR ls_msg IN lt_bopf_msg WHERE ( message IS BOUND )
                             ( msgid       = '00'
                               msgno       = '208'
                               severity    = 'E'
                               parameter_1 = CONV #( ls_msg-message->get_text( ) ) ) ).
      ev_result = if_fpm_constants=>gc_event_result-failed.
      RETURN.
    ENDIF.

    " The root form shows the new 'Affected Areas' text after the dialog closed
    zcl_moc_scope_service=>gv_refresh_pending = abap_true.
  ENDMETHOD.

ENDCLASS.
```

## 9. One-time migration `ZMOC_SCOPE_MIGRATE`

Sets the new field for MOCs created before go-live. All code treats blank as Single Area anyway; the migration makes worklist filters and reports clean.

```abap
*&---------------------------------------------------------------------*
*& Report ZMOC_SCOPE_MIGRATE
*&---------------------------------------------------------------------*
*& Object ID   : CRQ<new> (Global / Multiple-Area MOC)
*& Description : One-time conversion - MOCs created before go-live get
*&               Area Scope 'S' (Single Area). Only the new custom field
*&               Z_MOC_SCOPE is written; no BOPF logic is involved.
*&---------------------------------------------------------------------*
REPORT zmoc_scope_migrate.

PARAMETERS p_test AS CHECKBOX DEFAULT abap_true.

START-OF-SELECTION.

  SELECT COUNT(*)
    FROM /iam/d_i_root
    WHERE application = @/iam/if_appl_c=>sc_application-moc
      AND z_moc_scope = @space
    INTO @DATA(gv_count).

  IF p_test = abap_true.
    WRITE: / |Test run: { gv_count } MOC(s) would get Area Scope 'S' (Single Area).|.
    RETURN.
  ENDIF.

  UPDATE /iam/d_i_root
     SET z_moc_scope = @zcl_moc_scope_service=>gc_scope-single
   WHERE application = @/iam/if_appl_c=>sc_application-moc
     AND z_moc_scope = @space.

  DATA(gv_updated) = sy-dbcnt.
  COMMIT WORK.

  WRITE: / |{ gv_updated } MOC(s) updated to Area Scope 'S' (Single Area).|.
```

## 11. Fallback without BOBX (plain custom table)

Use only if the Phase-0 spike fails.

| Element | Design |
| --- | --- |
| Table `ZMOC_D_MOC_AREA` | `MANDT`, `ISSUE_KEY` (`/BOBF/CONF_KEY`), `LOC_ROOT_KEY` (keys), `AREA_ID`, `AREA_CODE`, `AREA_NAME`, `CREATED_BY`, `CREATED_ON` |
| Buffer | Static table in `ZCL_MOC_SCOPE_SERVICE` keyed by issue key; the popup writes only to the buffer |
| Display text | Popup OK writes `Z_AREA_NAME` / `Z_UNIT_NAME` to ROOT through the service manager, so the MOC is "changed" and FPM asks for save on leave |
| Persist | `ZENH_MOC_CHANGE_REQUEST~SAVE` (after `EV_REJECTED = abap_false`): `DELETE` + `INSERT` for the issue key from the buffer, then clear the buffer |
| Cancel | Clear the buffer on `FPM_CANCEL` / leaving edit mode (AppCC exit) and after a rejected save |
| Delete | Post-exit of action `DELETE_ISSUE` or a periodic clean-up of orphans |
| Checks / determination | Read buffer first, then the table |
| Audit | Own change log or rely on the change document of `Z_AREA_NAME` |

The fallback needs about two extra days and carries the consistency risks listed in the design document (section 5) – which is why BOBX is recommended.
